# EauPtimize

EauPtimize est un outil de gestion des eaux usées qui aide à optimiser l'utilisation de l'eau en fonction des caractéristiques spécifiques des bâtiments. Développé dans le cadre d'un projet de PAi avec l'entreprise UrbanWater, il permet de simuler différents scénarios pour des types de bâtiments variés et de suggérer des solutions pour réduire la consommation d'eau.

## Fonctionnalités

- Simulation de l'utilisation de l'eau pour différents types de bâtiments.
- Calcul des ressources et des besoins en eau.
- Suggestion de solutions pour optimiser l'utilisation de l'eau.
- Interface utilisateur intuitive avec navigation entre différentes pages.

## Installation

1. Clonez ce dépôt sur votre machine locale.
2. Assurez-vous d'avoir Python 3.x et PyQt5 installés.
3. Installez les dépendances nécessaires :
   ```bash
   pip install -r requirements.txt
4. Lancez l'application
    ```bash
    python main.py
    
## Utilisation

1. Sélectionnez le type de bâtiment sur la page d'accueil.
2. Remplissez les champs d'entrée spécifiques au type de bâtiment sélectionné.
3. Cliquez sur "Calculer" pour obtenir les résultats et les suggestions d'optimisation.
